# AI 질문 생성 테스트 결과 — 11/10 회의

## 한 줄 요약

가짜 경험 기록 20개를 AI에 넣어 봤다. **질문은 명세대로 "해볼 것 2개 + 상상해보기 2개"가 매번 정확히 나오고, 출처도 붙고, 톤도 괜찮다.** 다만 네 개 중 한두 개는 "이걸 왜 묻지?" 싶은 밋밋한 질문이 섞인다. 프롬프트(AI한테 주는 지시문)를 다듬으면 고칠 수 있는 수준이고, 모델을 바꿀 문제는 아니다.

- 어디서 돌렸나: 학교 GPU 서버에 공개 모델(Qwen3.8-27B)을 올려서. 사용료 0원, 상업 이용 가능 라이선스
- 속도: 질문 4개 만드는 데 약 3초, 정리 확인 1.5초, 관련 경험 찾기 1초. 전부 명세 제한 안
- 테스트 20개 = 질문 생성 12 + 정리 확인(칩 추천) 4 + 관련 경험 찾기 4

### 질문 생성 총평

48개 질문 중 ✅ 28 · 🟡 14 · ❌ 6.

**잘 되는 것**
- 형식은 완벽. 12번 모두 해볼 것 2 + 상상 2, 출처 있음, 60자 이내, 반말체
- **"한 줄"에 쓴 고민을 제일 잘 받는다.** q03 "왜 만드는지 몰랐다" → "목적을 문서로 정리해볼까", q07 "내가 올린 건지 모르겠다" → "기여도를 숫자로 연결해볼까"
- 보강글에 구체적 장면이 있으면 질문도 구체적 (q04 봉사, q11 교환학생)

**아쉬운 것 — 세 가지 패턴**
1. **상상해보기가 약하다.** 해볼 것은 거의 다 쓸 만한데, 상상은 "안 했다면?"(q02), "일찍 끝냈다면?"(q09)처럼 뒤집기만 한 게 나온다. ❌ 6개 중 5개가 상상
2. **네 개가 겹친다.** q06은 해볼 것과 상상이 같은 얘기 두 번
3. **입력이 빈약하면 지어낸다.** q10처럼 보강글이 없으면 없는 장면을 만든다
4. (명세 위반) q09 "기한 연장"처럼 할 수 없는 가정이 1건

**고치는 방법** 프롬프트에 "상상해보기는 기록에 적힌 실제 선택 지점에서만", "네 질문은 서로 다른 지점을 짚을 것", "기록에 없는 행동은 만들지 말 것"을 추가. 모델 교체 없이 가능. 수정 후 같은 20개로 다시 돌려서 비교 예정.

## 2. 정리 확인 (저장 후 글에서 칩 추천) — 4개

사용자가 쓴 글을 주고 "해당하는 칩만 골라라"를 시켰다.

"내 질문 + 남의 공개 카드 5장"을 주고 "답이 될 만한 것만 관련 순으로, 이유 한 줄"을 시켰다. 카드 5장 중엔 일부러 상관없는 것(토익 스터디, 카페 알바 등)을 섞었다.

| 내 질문 | 섞어 넣은 무관 카드 | AI 결과 | 평 |
|---|---|---|---|

| r02 "매출만 보는 사장님 밑에서 내 기준을 뭘로 잡지?" | 유럽 여행, 해커톤 | 옷가게 알바 "매출 압박 속 개인 기준 설정" / 마케팅 인턴 "숫자 중심 상사 밑 기록법" / 편의점 "발주 권한으로 자율 기준". 여행·해커톤 제외 | ✅ |

## 4. 기획·디자인에 묻고 싶은 것

1. **상상해보기의 기준.** "안 했다면 어땠을까?"(q02) 같은 뒤집기 질문은 버리는 게 맞나? 아니면 그것도 가치가 있나?
2. **해볼 것의 현실성 기준.** 인턴·팀원 입장에서 "회의에서 먼저 의견 내기"(q07)는 해볼 것으로 괜찮은가, 부담인가?
3. **톤.** 질문은 반말체("~해볼까?")로 나오는데 이대로 가나? 정리 확인 후속 질문과 관련 경험 이유도 같은 톤으로 맞출지
4. **입력이 빈약할 때.** q10처럼 보강글이 없으면 질문 질이 떨어진다. 기록 화면에서 보강 한 줄을 더 강하게 유도할지, 아니면 질문 개수를 줄일지
5. **"왜 관련 있는지" 한 줄 유지 여부** (지은 확인 목록에 있던 것) → 테스트상 품질은 충분함
