기능 확인용 페이지

서버 기능이 어떻게 동작하는지 눌러 보는 곳입니다. 실제 앱 화면이 아니고 디자인도 아닙니다. 기록 입력 칸은 실제 7단계 화면을 줄인 것이고, 여기서 쓴 기록은 확인용 계정에만 쌓입니다.

들어가기

1. 기록 쓰기

* 표시는 꼭 채워야 합니다. 저장하면 서버가 이 기록으로 질문 4개를 만듭니다.

상태* 분야* 유형
기간* ~
규모방식 내 역할자율성

2. 내 기록과 질문

질문 종류: 더 적어보기(기록에 빠진 내용을 묻는 질문, 답을 적을 수 있음) · 해볼 것(내가 고를 수 있는 것을 바꾼 질문) · 상상해보기(내가 고를 수 없는 것을 바꾼 질문). 다시 만들기는 기록당 24시간에 1번, 그리고 더 적어보기에 답할 때마다 1번 더 됩니다.

3. 분석

기록이 3개(회차 기록 포함)부터 열립니다. 패턴은 기록 2개 이상에서 되풀이된 것만 나옵니다. 새 기록을 쓴 뒤에는 "다시 분석"을 눌러야 반영됩니다.

4. 알림함

실제 푸시는 앱이 있어야 울립니다. 여기서는 알림함에 쌓이는 모양만 봅니다. 기록의 "새 질문 알림 흉내"를 같은 날 여러 번 누르면 알림이 늘지 않고 개수만 오릅니다.
