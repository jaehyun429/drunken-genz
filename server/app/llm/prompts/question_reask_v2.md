## 다시 요청
위 기록으로 질문을 한 번 만들었는데, 규칙에 맞는 질문이 {have}개뿐이다. {need} 더 필요하다.

### 이미 통과한 질문
다시 내지 않는다. 같은 칩이나 같은 사실을 바꾼 질문도 겹친 것이다.
{kept}

### 규칙에 어긋나 버린 질문과 이유
같은 꼴을 다시 내지 않는다. 말만 바꿔서 다시 내지도 않는다. 글자 수를 넘겨 버린 질문은 줄여서 다시 내도 된다.
{dropped}

### 할 일
- 위 두 목록에서 쓰지 않은 칩이나 문장에서 출발해 {need}만 새로 만든다. write_more 는 내지 않는다.
- "문장 틀"과 "만들면 안 되는 질문" 규칙은 그대로 지킨다.
- 기록에 더 쓸 재료가 없으면 지어내지 말고 빈 목록을 낸다.
