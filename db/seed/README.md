## 찾는 방법

- 대외활동 사이트(링커리어 등)는 **어떤 활동이 있는지 찾는 데만** 쓰고, 이름·주최·기수는 **주최 공식 페이지나 모집 공고**를 보고 적는다
- 이름·주최·기수 같은 사실만 손으로 옮긴다. 설명글·이미지는 안 가져온다
- 자동 수집(크롤링, 확장 프로그램, 매크로)은 안 한다 (CLAUDE.md 13장, 사이트 약관). 한 사이트 목록을 통째로 베끼지 않는다
- K-Startup API(창업 쪽)는 기수 있는 창업 프로그램 몇 개를 고르는 참고로만

## 칸 (첫 줄 머리글 그대로, 구글 시트 → 다운로드 → CSV)

| 칸 | 예 | 설명 |
|---|---|---|
| `name` | 멋쟁이사자처럼 대학 | 필수, 2~40자. 공고에 쓰인 이름 그대로 |
| `organizer` | 멋쟁이사자처럼 | 주최 |
| `period` | 13기 | 기수·연도. 기수마다 한 줄 (최근 1~2기면 충분) |
| `aliases` | 멋사\|멋사대학 | 최대 3개, `\|` 로 구분. **줄임말은 꼭** — 여기 없으면 줄임말로 못 찾음 |
| `genre` | 개발·IT | 분야 9개 중 하나, 글자 그대로 (가운뎃점 `·`) |
| `type` | 동아리·학회 | 유형 7개 중 하나, 글자 그대로 |
| `series_key` | | 보통 비워 둠 → 이름이 같으면 기수끼리 자동으로 묶임. 기수마다 이름이 달라지면 같은 글자를 직접 |
| `source_url` | 모집 공고 주소 | 확인한 곳. 검수용이라 DB엔 안 들어감 |

분야 9개: 행사 운영 / 개발·IT / 디자인·콘텐츠 / 음악·공연 / 연구·실험 / 교육·멘토링 / 경영·마케팅 / 서비스·응대 / 기타
유형 7개: 동아리·학회 / 팀플·공모전 / 대외활동 / 학생회·행사 / 아르바이트 / 봉사·멘토링 / 수업·캡스톤

## 넣기

```bash
cd server
python -m scripts.import_activities ../db/seed/official_activity.csv --dry-run   # 검사만
python -m scripts.import_activities ../db/seed/official_activity.csv             # 로컬에 넣기
DATABASE_URL='<Supabase 연결 주소>' python -m scripts.import_activities ../db/seed/official_activity.csv   # Supabase
```

틀린 줄이 있으면 몇 번째 줄이 왜 틀렸는지 나오고 아무것도 안 들어간다. 다시 돌려도 중복 안 생김 (같은 이름·같은 기수면 덮어씀).
